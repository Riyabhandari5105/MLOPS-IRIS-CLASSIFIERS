# Testing Strategy

## Test Files

1. test_preprocess.py
   - Tests data preprocessing
   - Duplicate removal
   - Missing values
   - Empty data

2. test_features.py
   - Tests feature engineering
   - Area calculations
   - Ratio calculation
   - Feature categories

3. test_validate.py
   - Tests data validation
   - Missing columns
   - Invalid species
   - Out-of-range values

4. test_training_pipeline.py
   - Tests model training
   - Prediction shape
   - Prediction probabilities

5. test_model_quality.py
   - Tests model predictions
   - Checks minimum accuracy
